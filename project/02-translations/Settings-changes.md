### 功能说明

Settings 是一个纯展示型的SVG图标组件，导出为 `S` 别名：

- **图标样式**: Ionicons风格的齿轮设置图标（viewBox 0 0 512 512）
- **组成**: 中心圆（r=48）+ 齿轮外圈路径
- **颜色**: 使用 `currentColor` 继承父元素文字颜色
- **导出方式**: 同时以 `default` 和命名导出 `S` 两种方式导出
- **使用场景**: DefaultLayout中的"任务管理"和"个人设置"导航项图标、Home页"个性化设置"功能图标
