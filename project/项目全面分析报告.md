## 一、项目概述

这是一个 **XYZW 游戏（咸鱼之王）的 Web 辅助工具**项目，核心目标是将开源项目 [w1249178256/xyzw_web_helper](https://github.com/w1249178256/xyzw_web_helper) 与 APK528 版本的增量功能合并，完成 **Naive UI → Arco Design** 的 UI 框架迁移，并最终部署到 Cloudflare Pages。

| 属性 | 值 |
|------|-----|
| 项目名 | xyzw-token-manager v2.0.0 |
| 项目类型 | 游戏自动化辅助 Web 应用 |
| 许可证 | CC-BY-NC-SA-4.0 |
| 部署方式 | Cloudflare Pages（通过 worker.js 代理） |
| 代码行数 | 约 806 个文件，源码约 80+ Vue/JS/TS 文件 |
| 当前阶段 | Phase 4（验证+部署），完成度 40% |

### 版本对照

| 版本 | 说明 | 地址 |
|------|------|------|
| A. 开源项目 | 基线源码（Vue 3 + Vite + Pinia） | https://github.com/w1249178256/xyzw_web_helper |
| B. 原生部署版 | 从 A 构建部署，无自定义修改 | https://xyzw-web-helper-2fu.pages.dev/ |
| C. 目标开发版 | APK528 提取的构建产物，包含大量自定义功能 | https://xyzw-web-helper-ena.pages.dev/ |

### 4.3 核心业务逻辑层

#### (1) WebSocket 通信机制

`xyzwWebSocket.js` 是整个项目的通信核心：

- **BON 协议**：使用二进制 BON (Binary Object Notation) 编码，通过 `lz4js` 进行压缩/解压
- **加密通道**：WsAgent 使用 `channel = "x"` 加密通道
- **命令节流**：`CmdDebounceMap` 定义了关键命令频率限制
- **错误码映射**：48 种游戏错误码到中文描述（签到、俱乐部、体力、道具等场景全覆盖）
- **自动重连**：最多 5 次，间隔 3 秒
- **心跳保活**：每 2 秒发送 `heart_beat` 命令
- **消息队列**：发送队列 50ms 轮询间隔
- **Promise 等待**：`waitingPromises` Map 实现请求-响应关联

#### (2) BON 协议实现

`bonProtocol.js` 实现了完整的 BON 编解码器：

- **DataReader**：二进制数据读取（支持 UInt8/Int16/UInt32/Int64/String/Map/Array 等类型）
- **DataWriter**：二进制数据写入
- **Int64**：64 位整数支持
- **LZ4 压缩/解压**：使用 `lz4js` 库
- **消息构造**：`ProtoMsg` 类封装消息结构

#### (3) Token 管理体系

`tokenStore.ts` 实现了完整的多 Token 管理：

- **多 Token 支持**：每个 Token 有独立的 WebSocket 连接和会话
- **6 种导入方式**：
  - `manual` — 手动输入 Base64 Token
  - `bin` — BIN 文件导入
  - `url` — URL 链接导入
  - `wxQrcode` — 微信扫码登录（884 行实现）
  - `singlebin` — 单个 BIN 文件
- **双层持久化**：`useLocalStorage` + IndexedDB（`idb` 库）
- **Token 分组**：支持按分组管理多个 Token，含颜色标识
- **跨标签页协调**：通过 localStorage 实现多标签页连接状态同步
- **Token 加密/解密**：`transformToken()` + `generateRandomSeed()`
- **自动刷新**：`refreshGameToken()` / `refreshFromUrl()`（含 CORS 处理）

#### (4) BIN 文件处理

- `bin.vue`：批量 BIN 文件导入界面
- `singlebin.vue`：单个 BIN 文件导入
- 支持从 Capacitor 打包的 APK BIN 文件中提取 Token 数据
- `transformToken()` 对 Token 进行编码转换

#### (5) 答题功能

`studyQuestionsFromJSON.js` + `StudyChallengeCard.vue`：

- 从 `public/answer.json` 加载答题数据
- **多路径回退加载**：BASE_URL → `/answer.json` → `answer.json`
- `testStudyQuestions.js` 包含测试题库（428 行）
- UI 组件 `StudyChallengeCard.vue` 提供答题挑战界面

#### (6) 图片导出

`imageExport.js`：

- 使用 `html2canvas` 将 HTML 元素导出为图片
- `crossPlatform.js` 中的 `downloadFile()` 实现跨平台文件下载
- Web 环境下使用 Blob URL + `<a>` 标签下载
- 原 Capacitor 代码已替换为纯 Web 方案

#### (7) 事件系统

`stores/events/` 目录（11 个文件）：

| 文件 | 功能 |
|------|------|
| `index.ts` | 事件总线（`$emit` / `emitPlus`） |
| `ack.ts` | 消息确认事件 |
| `activity.ts` | 活动事件 |
| `chat.ts` | 聊天事件 |
| `clock.ts` | 时钟/定时事件 |
| `hangup.ts` | 挂机事件 |
| `legion.ts` | 军团事件 |
| `role.ts` | 角色事件 |
| `study.ts` | 答题事件 |
| `team.ts` | 团队事件 |
| `tower.ts` | 爬塔事件 |

使用 `event-emitter3` 实现发布/订阅模式。

## 七、关键特性深度分析

### 7.1 WebSocket 通信架构

```
用户界面 (Vue Components)
    ↓
tokenStore.ts (连接管理 + 会话协调)
    ↓
xyzwWebSocket.js (BON 编解码 + 错误处理)
    ↓
wsAgent.js (底层 WS + 心跳 + 重连 + 队列)
    ↓
游戏服务器
```

### 7.2 数据持久化三层架构

```
Layer 1: Pinia Store (响应式状态)
Layer 2: useLocalStorage (localStorage 持久化)
Layer 3: IndexedDB (idb 库，二进制数据存储)
```

| `/api/hortor` | comb-platform.hortorgames.com | Hortor 游戏登录接口 |

### 7.4 Cloudflare Pages 部署

- `wrangler.toml` 包含 Cloudflare Pages 配置
